# Mac Click Recorder · 클릭 녹화기

Mac 메뉴 막대에서 화면 좌표와 클릭 간격을 기록하고 한 번 재생하는 개인용 앱입니다. 외부 라이브러리·서버 없이 Swift/AppKit으로 만들었습니다.

## 실행

`build/클릭 녹화기.app`을 실행하세요. 화면 위쪽 메뉴 막대의 `◉`가 앱입니다. Dock 아이콘은 표시하지 않습니다.

최초 실행 시 시스템 설정 → 개인정보 보호 및 보안에서 **입력 모니터링**과 **손쉬운 사용** 권한을 허용하세요. 목록에 없다면 `+`로 앱을 추가하세요. 권한을 변경한 뒤 종료·재실행해야 할 수 있습니다. 화면 녹화 권한은 필요하지 않습니다.

## 단축키

| 동작 | 기본 단축키 |
|---|---|
| 녹화 시작 / 종료 | Control + Option + Command + R |
| 선택한 녹화 한 번 재생 | Control + Option + Command + P |
| 즉시 중지 | Control + Option + Command + Esc |

단축키 설정에서 마지막 키를 변경할 수 있습니다. 영문 키는 US 키보드의 물리 위치를 기준으로 합니다. 등록 충돌이 발생하면 메뉴에 표시하고 녹화·재생을 막습니다.

1. 창을 준비하고 녹화 단축키를 누릅니다. 3초 카운트다운 후 `● REC`가 표시되면 클릭합니다.
2. 같은 단축키로 종료합니다. 최대 180초에 자동 종료됩니다.
3. 날짜·시간 이름으로 저장됩니다. 메뉴에서 이름 변경·삭제·선택할 수 있습니다.
4. 대상 창 위치와 크기를 녹화 때와 같게 맞추고 재생 단축키를 누릅니다. 첫 클릭 전 대기와 마지막 클릭 후 남은 시간도 유지됩니다.
5. 필요하면 중지 단축키로 즉시 중단합니다.

## 범위

- 활성 모니터 한 개에서 좌클릭·우클릭·더블클릭을 지원합니다.
- 드래그, 스크롤, 키 입력, 보조키 조합 클릭은 저장하지 않습니다. 미완료 클릭도 제외합니다.
- 재생은 실제 마우스 포인터를 움직입니다. 재생 중에는 마우스를 사용하지 마세요.
- 화면 구성이 바뀌면 재생을 중단합니다. 창이나 버튼을 자동으로 찾아주지는 않습니다.
- 운영체제 스케줄링과 대상 앱 로딩 속도에 따라 실제 처리 시간에는 차이가 있습니다. 합성 입력을 받지 않는 앱은 지원되지 않을 수 있습니다.
- 앱 자체 메뉴 클릭은 제외합니다. 녹화 시작·종료는 단축키 사용을 권장합니다.
- 자동 로그인 실행, 무한 반복, 편집, 클라우드 업로드는 포함하지 않습니다.

## 저장 위치

`~/Library/Application Support/ClickRecorder/Recordings/`

UUID별 JSON 파일에 좌표, 상대 시간, 클릭 종류, 화면 구성을 저장합니다. 손상 파일은 삭제하지 않고 건너뜁니다. 앱 설정은 `local.tei.ClickRecorder` 사용자 기본 설정에 저장됩니다.

## 빌드·테스트

Apple Command Line Tools와 Swift가 설치된 Mac에서:

```sh
./build.sh
./test.sh
```

현재 Mac 아키텍처로 최적화 빌드하고 로컬 ad-hoc 서명을 적용합니다. 공개 배포용 Developer ID 서명·공증은 포함하지 않습니다. 재빌드하거나 앱 위치를 바꾸면 macOS 권한을 다시 허용해야 할 수 있습니다.

자동 검증은 JSON 저장·복원·변경·삭제, 클릭 순서·타이밍, Retina 화면 메타데이터, 손상·잘못된 데이터 거부, 취소된 재생 콜백 무효화를 확인합니다.

권한 허용 후 수동 검증: TextEdit·Finder 등에서 좌우·더블클릭 재생, 녹화 중 드래그 제외, 재생 중 긴급 정지, 3분 자동 종료, 재실행 후 목록 복원, 단축키 충돌 및 화면 변경 시 차단을 확인하세요.
