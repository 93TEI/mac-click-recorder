# Mac Click Recorder · 클릭 녹화기

Mac 메뉴 막대에서 화면 좌표·키보드 입력·동작 간격을 기록하고 한 번 재생하는 개인용 앱입니다. 외부 라이브러리·서버 없이 Swift/AppKit으로 만들었습니다.

## 실행

`build/클릭 녹화기.app`을 실행하세요. 화면 위쪽 메뉴 막대의 `◉`가 앱입니다. Dock 아이콘은 표시하지 않습니다.

최초 실행 시 시스템 설정 → 개인정보 보호 및 보안에서 **입력 모니터링**과 **손쉬운 사용** 권한을 허용하세요. 목록에 없다면 `+`로 앱을 추가하세요. 권한을 변경한 뒤 종료·재실행해야 할 수 있습니다. 화면 녹화 권한은 필요하지 않습니다.

## 단축키

| 동작 | 기본 단축키 |
|---|---|
| 녹화 시작 / 종료 | Control + Option + Command + R |
| 선택한 녹화 한 번 재생 | Control + Option + Command + P |
| 즉시 중지 | Control + Option + Command + Esc |

단축키 설정에서 마지막 키를 변경할 수 있습니다. 영문 키는 US 키보드의 물리 위치를 기준으로 합니다. 등록 충돌이 발생하면 메뉴에 표시하고 녹화·재생을 막습니다.

1. 창을 준비하고 녹화 단축키를 누릅니다. 3초 카운트다운 후 `● REC`가 표시되면 클릭하거나 키보드를 입력합니다.
2. 같은 단축키로 종료합니다. 최대 180초에 자동 종료됩니다.
3. 날짜·시간 이름으로 저장됩니다. 메뉴에서 이름 변경·삭제·선택할 수 있습니다.
4. 대상 창 위치와 크기를 녹화 때와 같게 맞추고 재생 단축키를 누릅니다. 첫 클릭 전 대기와 마지막 클릭 후 남은 시간도 유지됩니다.
5. 필요하면 중지 단축키로 즉시 중단합니다.

## 범위

- 활성 모니터 한 개에서 좌클릭·우클릭·더블클릭과 키보드 입력을 지원합니다.
- 문자 키, Enter, Tab, 방향키, 키 반복과 Command·Shift·Option·Control·Fn 조합을 기록합니다. 보조키 조합 클릭도 지원합니다.
- 보조키는 클릭·키 입력 시점의 상태를 재현합니다. 보조키만 단독으로 누르는 동작, 좌우 보조키 구분 및 Caps Lock 전환 자체는 기록하지 않습니다.
- 드래그와 스크롤은 저장하지 않습니다. 미완료 클릭은 제외하고, 종료 때 누르고 있던 일반 키에는 해제 이벤트를 추가합니다.
- 앱의 녹화·재생·중지 단축키는 저장하지 않습니다.
- 물리 키 위치를 재생하므로 키보드 배열과 한글·영문 입력 소스를 녹화 당시와 같게 맞추세요. IME 조합 결과 문자열을 직접 저장하지는 않습니다.
- 키보드만 녹화할 수도 있습니다. 키 입력은 재생 시 포커스를 가진 앱으로 전달됩니다.
- 보안 입력이 켜져 있으면 녹화를 시작하지 않습니다. macOS가 보호하는 암호 필드의 입력은 캡처되지 않을 수 있습니다. 녹화 중 입력은 로컬 JSON에 저장되므로 민감한 내용은 입력하지 마세요.
- 재생은 실제 마우스 포인터를 움직입니다. 재생 중에는 마우스와 키보드를 사용하지 마세요. 긴급 중지는 언제든 가능합니다.
- 화면 구성이 바뀌면 재생을 중단합니다. 창이나 버튼을 자동으로 찾아주지는 않습니다.
- 운영체제 스케줄링과 대상 앱 로딩 속도에 따라 실제 처리 시간에는 차이가 있습니다. 합성 입력을 받지 않는 앱은 지원되지 않을 수 있습니다.
- 앱 자체 메뉴 클릭은 제외합니다. 녹화 시작·종료는 단축키 사용을 권장합니다.
- 자동 로그인 실행, 무한 반복, 편집, 클라우드 업로드는 포함하지 않습니다.

## 저장 위치

`~/Library/Application Support/ClickRecorder/Recordings/`

UUID별 JSON 파일에 좌표, 상대 시간, 클릭 종류, 키 코드·누름/해제·보조키·반복 여부, 화면 구성을 저장합니다. 기존 v1 클릭 녹화는 그대로 읽으며 새 녹화는 v2 형식입니다. 손상 파일은 삭제하지 않고 건너뜁니다. 앱 설정은 `local.tei.ClickRecorder` 사용자 기본 설정에 저장됩니다.

## 빌드·테스트

Apple Command Line Tools와 Swift가 설치된 Mac에서:

```sh
./build.sh
./test.sh
```

현재 Mac 아키텍처로 최적화 빌드하고 로컬 ad-hoc 서명을 적용합니다. 공개 배포용 Developer ID 서명·공증은 포함하지 않습니다. 재빌드하거나 앱 위치를 바꾸면 macOS 권한을 다시 허용해야 할 수 있습니다.

자동 검증은 JSON 저장·복원·변경·삭제, 클릭 순서·타이밍, Retina 화면 메타데이터, 손상·잘못된 데이터 거부, 취소된 재생 콜백 무효화를 확인합니다. 키보드 전용·혼합 타임라인, 키 반복·해제, 앱 단축키 제외, v1 호환성도 확인합니다.

권한 허용 후 수동 검증: TextEdit·Finder 등에서 좌우·더블클릭 재생, 영문·한글 입력, Enter·방향키·Command+A·Shift 선택, 키를 누른 상태에서 중단, 녹화 중 드래그 제외, 재생 중 긴급 정지, 3분 자동 종료, 재실행 후 목록 복원, 단축키 충돌 및 화면 변경 시 차단을 확인하세요.
